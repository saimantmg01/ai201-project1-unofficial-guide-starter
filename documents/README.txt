HUNTER COLLEGE HOUSING AND COMMUTING CORPUS

This folder contains one plain-text document per source listed in planning.md
and README.md. The files are numbered to preserve the source-list order.

Each document contains:

- Source title and type
- Original URL
- Retrieval date
- Clean factual notes suitable for chunking and embedding
- A reliability note that distinguishes official information from student
  experiences

Official sources were summarized from accessible page content. Reddit threads
were summarized only when their public text was retrievable. Threads that were
unavailable through the main Reddit site were retrieved through their public
Old Reddit pages and RSS feeds.

For grounded answers, prefer official Hunter, CUNY, MTA, and NYC documents for
policies, routes, rights, and safety. Use Reddit documents only to describe
individual student experiences and recurring concerns.
